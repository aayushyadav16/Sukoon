# Sukoon music files

Drop your own .mp3 files here to make the player produce sound.
File names must match `src/data/songs.ts`:

bus/     song1.mp3 through song10.mp3
dance/   dance-01.mp3 through dance-13.mp3
love/    love-01.mp3 through love-07.mp3
salon/   salon-01.mp3 through salon-16.mp3

Missing files never crash the app - the player shows a friendly message instead.
